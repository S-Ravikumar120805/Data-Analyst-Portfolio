Project Overview

This project focuses on analysing supermarket sales data using advanced SQL queries. The goal is to extract meaningful business insights about sales performance, customer purchasing behaviour, and product performance.

Tools & Technologies:
MySQL 8.0+
MySQL Workbench
SQL

Database Tables:
Products
Customers
Sales

SQL Concepts Used:
SELECT, WHERE, ORDER BY
Aggregate Functions (SUM, AVG, COUNT)
GROUP BY and HAVING
INNER JOIN and LEFT JOIN
Subqueries
Common Table Expressions (CTEs)
CASE Statements
Window Functions (RANK, DENSE_RANK)
Moving Averages
Indexes and Constraints
