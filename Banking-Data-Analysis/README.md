Banking Data Analysis Dashboard using Power BI

Project Overview:
This project focuses on analysing banking data using Microsoft Power BI to create an interactive dashboard.

Tools & Technologies:
Microsoft Power BI
DAX
Data Modelling
Data Visualization
Data Model

The project includes the following tables:
Accounts
Branches
Cards
Customers
Loans
Measure Table

Project Objectives:
Explore banking-related data.
Organize data using relationships.
Create interactive visualizations.
Present useful business insights.
